# Frontend
- React + Vite
- IndexedDB as a local cache
- Typescript should be used in all future code

# Backend
- NodeJs API server
- Drizzle ORM
- SQLite Database
- Files stored in media directory with links in the database
- Typescript should be use in all future code

# Data Storage
## SQLite/Database
- Milestones
- Categories
- Settings
- Migration State

## Filesystem
- Images
- Audio
- Video
- Other attachments

## URL/API Layer
- Serves files to frontend

# Authentication
- Currently this is a single-user, locally-hosted app
- No authentication is required
- User scoping of data is not required
